# Orca Plugin Catalog

Add this catalog to Orca under **Settings → Plugins → ⋯ → Catalog sources…**:

```text
https://github.com/truongthanhquan/orca-plugin-catalog.git
```

The catalog contains:

- `truongthanhquan.cloudflare-relay` — Cloudflare Relay Setup 1.0.0

Install link:

```text
orca://plugins/truongthanhquan.cloudflare-relay?catalog=https://github.com/truongthanhquan/orca-plugin-catalog.git
```
